# PÁNICO — sitio web + EPK

Sitio estático preparado para GitHub Pages.

## Estructura
- `index.html` — página principal.
- `epk.html` — EPK digital con versión imprimible.
- `EPK-PANICO.pdf` — EPK PDF.
- `data.js` — ÚNICO archivo que debes editar para nombres, biografías, enlaces, merch y contactos.
- `assets/panico-logo.png` — logo principal.
- `assets/photos/` — fotos de la banda e integrantes.

## Publicar en GitHub Pages
1. Crea un repositorio, por ejemplo `panico-banda`.
2. Sube todos los archivos manteniendo la estructura.
3. En GitHub: Settings → Pages → Deploy from branch → `main` / root.
4. GitHub entregará una URL tipo `https://usuario.github.io/panico-banda/`.

## Antes de publicar
Edita `data.js`:
- nombres y roles de los 4 integrantes
- biografías
- enlaces de YouTube/Drive
- correo de booking
- WhatsApp de booking
- enlaces de merch

Agrega las fotos en `assets/photos/` con los nombres indicados.

## Recomendación de evolución
Cuando exista dominio propio, solo hay que apuntar el dominio a GitHub Pages o migrar estos mismos archivos a un hosting. La estructura no depende de un backend.
